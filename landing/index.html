For anyone who lets AI build on their computer

Let AI build for you, without handing it your whole computer.

Your AI agent gets the keys to the room, not the house.

Tini Family works alongside AI agents like Claude Code. It gives the agent only what the task needs, checks every step it takes, and inspects the result before anything leaves your computer. For first-time vibe coders and seasoned engineers alike.

The problem

AI doesn’t just answer anymore. It acts.

Coding agents open files, save files and run programs on your computer. Students build class projects with them, interns use them on company code, and people who have never written a line of code build whole apps. They all do it on the same computer that holds their IDs, tax forms, passwords and personal photos.

The student

Builds a class project on the laptop that also holds an ID scan and tax forms.

The intern

Points an agent at company code that sits next to a file full of passwords.

The freelancer

Hands over client photos that quietly carry the exact place they were taken.

The first-time vibe coder

Clicks Yes forty times, because nobody can read forty technical prompts.

These agents act with your account’s access. The settings that limit them exist, but they’re optional and technical, so they’re easy to miss.

How it works

One prompt, one fence, one green light.

    You ask.

Safety

Three layers between the agent and your files

Each layer catches what the one before it can’t see.

  1. 1

    It works on copies.

    Before the agent starts, Tini copies only the folders the task needs into a separate project folder. The agent works there. Your originals are never touched, so the worst it can damage is its own copy.

  2. 2

    Every step is checked before it happens.

    An agent works in steps: open a file, save a file, search, run a program. Before each step runs, Tini checks where it points. Inside the project folder, it goes ahead. Anywhere else, it’s blocked with a plain reason, and if it’s a folder you might want to share, you’re asked. Your typing and the AI’s thinking aren’t touched, only what it does on your computer.

  3. 3

    Programs run inside the Mac’s own sandbox.

    When the agent runs a program in the terminal, macOS itself walls it in: it can’t read the rest of your home folder or reach websites you didn’t approve, even with a disguised command.

    Tested In our tests the sandbox stopped a disguised read that slipped past the step check.

Privacy

Private by design

Rules decide, not AI.

AI helps Tini label the fence and suggest which files fit a request. Plain code checks every suggestion against what you named, and code alone decides what gets in. The AI can’t add a single folder.

Tina checks your files on your Mac.

Finding keys, passwords, ID documents and hidden photo data is done by regular code on your own computer. Nothing is uploaded to be checked.

Two AIs, two different views.

The agent doing the work sees the files you let in, and only those. The helper AI that plans and explains sees folder names, file counts and findings with the secret hidden, never your files.

Tested against a tricked AI.

We fed the planner a deliberately malicious answer asking for SSH keys and extra folders. The code threw out every extra request.

Photos lose their hidden location.

Phones store the exact spot a photo was taken, often your home, inside the file. Tini removes it from the copies before the agent sees them, so it can’t end up on a website.

Questions

Fair questions.

Doesn’t Claude Code already do this?

It has the parts: permission rules, hooks and a sandbox. But they’re optional and technical, and by default the sandbox still lets programs read your whole home folder. Tini sets up all three layers from your one request, in plain words, and Tina checks the work afterwards.

What if the AI is wrong?

Rules decide, not AI. The AI suggests labels and which files fit the request, and plain code checks every suggestion against what you named. If both AI providers are down, the fence, the inspection and the fixes still work, with built-in wording.

Is this a chatbot?

No. It’s a workspace with a fence. You say what you want in a prompt bar, the yard shows what the agent is doing, and your history is a timeline of turns. You don’t need to know how to code: every card is in plain words, and you only get asked when access changes.

Does it only build websites?

Website builds are tested end to end, from prompt to launch. We also tested fence planning on other Claude Code tasks: analyzing a spreadsheet and making charts, renaming photos in a folder, and a follow-up request that needs nothing new.

What’s simulated in the demo?

The ~/.ssh attack. A test harness sends a read of ~/.ssh/id_rsa through the real fence check and shows the real block, labeled “simulated” on screen. The file is never opened. The client, its photos and its key are fake data made on our laptop.
